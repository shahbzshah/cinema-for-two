# Cinema for Two — Private Screening Room

Sync movies across miles, share live reactions, and stamp every date night into your shared passport.

- **Live sync:** PeerJS (WebRTC, browser-to-browser) — no backend, no accounts.
- **Memories:** append-only JSONL log, saved on-device + downloadable `.jsonl` file. Reopen the same room code tomorrow and continue where you paused.
- **Play:** YouTube links, direct video URLs, local files (both pick the same file), or sample clips.

Open `index.html` or visit the Pages site. See `JSONL-FORMAT.md` in the workspace for the memory line format.
